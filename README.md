# Hongjian · 虹笺

虹笺是一款面向 macOS 的彩色桌面整理与创作者工作流助手。

它帮助用户整理桌面文件、识别旧版本与安装包、集中管理截图，并通过七彩分类提供快捷操作、照片整理、专注模式、便签提醒和每日回顾。

## 主要功能

- 桌面文件安全归类，操作前先预览
- 识别旧版 App 与安装包，保留最新版本
- 集中整理截图、文档与压缩包
- 截图收集架支持悬停展开和拖拽使用
- 七种颜色对应不同工作功能
- 中文与英文产品介绍

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```
